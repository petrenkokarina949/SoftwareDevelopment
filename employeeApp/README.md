# Employee Payslip

## Project Description

This is a simple Kotlin project for calculating an employee payslip.


## Features

- Calculates normal pay
- Calculates overtime pay
- Calculates gross pay
- Calculates bonus
- Calculates tax
- Calculates pension
- Calculates net pay
- Displays the full payslip

## Getting Started

1. Open the project in IntelliJ IDEA.
2. Run the program.
3. Choose an option from the menu.
